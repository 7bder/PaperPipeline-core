# 项目文件组织与命名规范（P0 定，全程遵守）

> 写论文是**串行管线**，目录与文件名的**序号必须体现阶段位置**，做到"看文件名即知在第几阶段"。
> 本规范必须**同时**满足 orchd 约束与本 skill 约束（§4 给出联合检查表）。
> 本文件只保留对新项目普适的规范；历史项目的迁移方案与实施实证已移至 `CHANGELOG.md` 的 D-18 沿革条目。

## 1. 命名规则

1. **目录**：`NN-<域>`，NN 为两位阶段号（下表）。
2. **文件**：`<NN><ii>-<kebab-语义>.<ext>`，NN 与所在目录同号，`ii` 为域内两位序号（起始号不强制 00/01，以该项目首产物实际形态为准；同一域内连续、新增用下一位、不重排）。
3. **语言**：文件名一律 **ASCII kebab-case**（跨平台、git、LaTeX、shell 全安全）。**中文仅允许**出现在 `10-data/raw/**` 的原始件（保留原名，另在 `10-data/raw/MAPPING.md` 登记中英对照）。
4. **工具约定名不加号**：`SKILL.md`、`README.md`、`.gitignore`、`.orchd/**`、引擎跟踪的 `ROADMAP.md`。
5. **派生物必须在文件头标注**：LaTeX（`% GENERATED — do not edit`）、由脚本生成的 md（`<!-- generated by <script> -->`）。

**三分原则（治乱的核心）**：
- **产物**（进 git、被任务声明）→ 放所属阶段目录并编号；
- **临时物**（候选清单、抓取中间件、原始抽取文本）→ 进同级 `scratch/` 或 `79-archive/`，**永不**混入产物目录；
- **原始件**（不可再生）→ `10-data/raw/**` 只增不改，附 `MAPPING.md`。

## 3. 与 orchd 的对应（声明路径怎么写）

- 任务声明的 `files_to_read` / `files_to_edit` 一律用**项目根相对路径**（如 `30-manuscript/sections/31-introduction.md`）。
- 一个任务**一个主产物**：任务 id 与产物名同源（`task-write-introduction` → `31-introduction.md`），便于"任务→产物"双向定位。
- `files_to_edit` ≤5（超触发 E029）；连带改动的既有文件**直接写入 files_to_edit**，不用 `exempt_files`。
- `verify_command` 用编号后的路径：`python 70-tools/70-verify.py task-<id>`（引擎不关心目录名，只要求命令可执行）。
- **`.orchd/**` 只由引擎写**；引擎自带的系统设计文档归 `.orchd/docs/`，**不要**在项目根另开 `docs/`（真实项目实测出现过 `docs/` vs `documents/` 同名混淆，出处见 `CHANGELOG.md` D-18）。

## 4. 联合约束检查表（新项目立项时逐条过）

| # | 约束 | 来源 | 检查 |
|---|---|---|---|
| 1 | 路径稳定可声明、全部相对项目根 | orchd（files_to_read/edit） | 无绝对路径、无 `..` 越界 |
| 2 | 单任务 ≤5 files_to_edit | orchd（E029 告警） | 超标即拆任务 |
| 3 | `verify_command` 可执行（默认 120 s，例外通道 `amend --verify-timeout-seconds` 上界 600 s） | orchd（verify 预算） | 脚本离线、秒级 |
| 4 | 不手改 `.orchd/**`、`ROADMAP.md` 只由引擎/用户改 | orchd（红线） | 目录权限与纪律 |
| 5 | 序号体现 P0–P6 阶段位置 | skill | 目录与文件名前缀一致 |
| 6 | 产物 / 临时物 / 原始件三分 | skill | 无临时物落在产物目录 |
| 7 | 单一真源（md 真源，tex 派生物） | skill | 派生物头部有 GENERATED 标记 |
| 8 | 中文仅现存于 `raw/`，且有 MAPPING | skill | 其余全 ASCII |
| 9 | 需求单先于文献库（`20-claims-map.md` 先于 `22-refs.json` 更新） | skill（顺序铁律） | claims_map 存在且非空 |
| 10 | 图号/表号与文件名解耦（编号在图注与正文，不在文件名里另起一套） | skill | `figures/data/fig_*` 与 `Fig. N` 有映射表 |
