# md 单一真源与派生物分工（来源：`references/40-draft-to-latex.md`、真实定稿合稿脚本实测）

本碎片是**跨出版社共性**：换任何目标刊，下面每一条都仍然成立。目标刊专属的引用形态在
`elsevier-numbered.md`。

1. 文字真源只有一处：`30-manuscript/*.md`（正文、图注、表格、文献表指针、待确认项清单）。
   `60-latex/**` 与其 `.tex` 是派生物，只承担版式（模板、字体、双栏、页边、参考文献样式）。
2. **禁止在 `.tex` 里手工改句子**。生成器须在 `.tex` 头部写入
   `% GENERATED — do not edit; change manuscript/*.md and re-run`
   （守卫：产物缺这一行即视为有人可能手改过，判不合格）。
3. 排版阶段发现必改之处，改 md → 重跑生成器；直接改 tex 的代价是 md 与 tex 立即分叉，
   前面做过的全部机检（编号、图表覆盖、术语、预算）同时作废。
4. 进入 LaTeX 段的时机只在内容定稿（`finalize`）之后。这条是顺序约束，不是偏好：
   提前进排版层必然触发第 3 条。
5. 合稿必须是确定性的：**同一输入字节一致**（已验幂等）。任何"每次跑出一份不同草稿"
   的实现（随机排序、dict 序不稳定、写入时间戳）都判不合格。
6. 作者确认项**上收为单一清单**：正文侧残留必须为 0，清单集中在文末，每条给出所属小节与
   句首若干词以便回指。机检：合稿后正文 `forbid` 掉 `TODO` / `TBD` / `[需作者确认]`
   （出处定稿的 `verify_manifest` 即用这三串），并断言清单节存在。
7. 术语归一在合稿期自动完成并**写进产物**，不是口头结论：如 `wt %`→`wt%`、ASCII 下标统一。
   归一后的词形须在正文、图注、表中一致（`scripts/45-consistency-check.py` 判据③）。
8. 字数预算判定写进产物（供断言回读）：报告 body 词数、是否落在预算区间、图注数与被引条目数。
   预算区间来自领域档，不得在脚本里硬编码某个项目的数字。
9. 图注与表的文字来自真源，tex 侧只决定位置与样式；同一张图不得有两份图注真源。
